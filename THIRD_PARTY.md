# Components

The app runtime contains original Java/HTML/CSS/JavaScript and uses Android platform APIs. It bundles separately executed NTFS-3G and e2fsprogs utilities; it does not bundle OS images, proprietary firmware or Ventoy payloads.

The Gradle wrapper bootstrap was reused from the existing local Android project; Gradle is Apache-2.0 licensed: https://github.com/gradle/gradle/blob/master/LICENSE . Android SDK/AGP, Java and Node are development tools, not embedded app runtime libraries. Retain upstream notices if importing additional components in future. Native tool notices and corresponding source archives accompany binaries. Future bootloader engines require their own redistribution review.

Filesystem check/limited-repair executables: dosfstools4.2 fsck.fat (GPL3+, https://github.com/dosfstools/dosfstools) and exfatprogs1.3.0 fsck.exfat (GPL2, https://github.com/exfatprogs/exfatprogs) are now bundled as separately executed API23 tools for four ABIs. Exact cached upstream archives, licenses, original build scripts and shared I/O bridge accompany the APK through its corresponding-source export. No upstream source patches; Android builds disable dosfstools iconv and retain its CP850 fallback. The checker uses upstream Unicode long-name handling; short-name code pages other than CP850 are not selected here. App exFAT/FAT/GPT formatting code remains original.

F2FS1.17.0 mkfs/fsck (GPL2; https://kernel.googlesource.com/pub/scm/linux/kernel/git/jaegeuk/f2fs-tools/) is separately executed with an original argv0 entry adapter. Exact307,238-byte source archive at commit83fd39a184df96db5def895ddc55bf68e720ef76, explicit API23 config/build script and licenses accompany the source export. No kernel driver, SELinux/sparse/lz4/lzo dependency or mount capability is added. Uses cached static libuuid from e2fsprogs; root ownership0:0, discard disabled.

UI compatibility build: TypeScript5.7.3 (Microsoft, Apache-2.0) transpiles owned UI sources to ES5. Its small standard emitted helper routines are included in generated JavaScript; the license is retained in LICENSES/typescript.txt and the APK's third-party-notices.txt. The compiler itself is development-only. Acorn8.14.1 (MIT) is a development-only strict ES5 syntax parser and is not packaged in the app. Runtime polyfills and legacy CSS are original app code.

Native tools: NTFS-3G/ntfsprogs2026.9.28 (Tuxera; GPLv2+/LGPLv2+) and e2fsprogs1.47.4 (GPLv2 utilities, LGPLv2 ext/e2p, BSD uuid and MIT et/ss). Full upstream source archives, licenses, original MIT adapter/API23 shim and build scripts are in assets/native-corresponding-source.zip, exportable from About. Sources/builds remain on tablet; only bundled APK resources accompany phone installation. Original FAT12/16/32/exFAT engines remain Java code. NDK/compiler runtime notices are in assets/ndk-notices.txt. See native/README.md for exact versions, URLs and build integration. No third-party source files were edited; native/android_compat.h supplies the missing API23 hasmntopt function.

0.4 work: XZ for Java1.12,0BSD, built from official source using only Java8 classes. app/libs/xz-1.12.jar and LICENSES/xz-1.12.txt; source archive retained in third_party. No Java9 multi-release variants. Pure Java decoder,32MiB memory cap for archives. Development-only pycdlib1.22.0 (LGPL2.1) generates independent tiny ISO/Joliet/UDF fixtures; never bundled in APK.

WIM engine: wimlib1.14.5, Eric Biggers and contributors, official https://wimlib.net/. The separately executed wimlib-imagex CLI is GPLv3+; the libwim component offers LGPLv2.1+/GPLv3+ dual licensing without the disabled optional NTFS dependency. Full source, notices, original MIT file bridge/API23 shim and reproducible scripts accompany binaries in native-corresponding-source.zip. User-imported Ventoy data is not distributed in the APK; no scripts or executables from that package run.

0.8 ZSO: Lz4Block.java is an original Java implementation based on the public LZ4 block-format description, with original bounded ZSO framing. The already installed tablet liblz4.so is used only by development tests through Python ctypes, never packaged. Format references: https://github.com/lz4/lz4/blob/dev/doc/lz4_Block_format.md and the official OPL pc/ziso.py and modules/isofs/zso.c. Console raw naming references the official webMAN-MOD Game Paths & Covers documentation; .usbwb manifest and implementation are original. No upstream implementation code was copied for these Java engines.

## 0.10 native readers and converters

libarchive 3.8.11 (BSD and included component notices), XZ/liblzma 5.8.4 (0BSD and included licenses), and libchdr 0.3.0 commit 93d8c239ff0d4e8d7722985992649fce12d2463b (BSD-3-Clause, including LZMA SDK, miniz, Zstd and dr_flac notices) are separately executed static tools. Runtime source archives, original CLI/I/O/decoder-limit adapters, API23 build scripts and licenses accompany the in-app corresponding-source export. GPL2+ NTFS/ext reader CLIs use the existing NTFS-3G/e2fsprogs sources. The DMG Java engine is original code. No downloaded executable is run by the app.

The libarchive runtime-source archive retains exact, unmodified upstream runtime and build files; its USBWB-PROVENANCE.json records every retained file hash and the official full archive hash. Test suites and unrelated documentation are omitted from the compact APK source export. The full official archive is also retained in the project source ZIP. tools/package_archive_source.py reproduces this selection; scripts/build_archive.sh accepts either archive. Full component notices are in LICENSES and the app's third-party-notices.txt. libarchive registers only in-process supported filters, never external filter helpers. liblzma decoder memory is capped at 128MiB. Host-only chdman/MAME and its dependencies generate independent owned fixtures; they are not packaged or installed on Android.

## 0.11 WIM/USBExtreme additions

Original native/wim_tree.c is GPL3-or-later, linked with the already included wimlib1.14.5/imagex GPL3+ engine. scripts/build_wim.sh builds unmodified upstream objects, renames a copied main symbol, then links the original bounded adapter into the same executable. No extra full WIM engine or SDK download. Its raw stdout write adapter forwards only active tree-export data to fixed numbered virtual files through the existing bridge. Existing CLI behavior remains delegated to upstream imagex. Adapter/build files accompany corresponding sources.

UsbExtreme.java is an original Java implementation of the standard on-disk USBExtreme interface, informed by official OPL format references (pc/iso2opl/src/iso2opl.c and .h). No OPL implementation, loader, game or firmware is copied, bundled or downloaded. Title naming uses non-reflected polynomial0x04c11db7, initial0, terminatingNUL; it is not a cryptographic content checksum. Independent fixtures verify catalog field offsets, part names and every exported byte. Primary references are recorded in docs/ANDROID_TOOL_REVIEW.md.
