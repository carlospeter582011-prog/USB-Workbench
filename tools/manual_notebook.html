What I tested automatically — evidence and limits

Small test files · Custom-size tests now use raw-8MiB.img from the small pack; the old large test ZIPs are no longer needed for these basic round trips.. If your browser will not open these links, use Android Files → Downloads and extract the ZIP there. No OS, game or boot image is included. The small pack extracts to about 45 MiB; all basic custom-size round trips can use the 8 MiB source. Keep at least 128 MiB free for their outputs.

Formatting, writing images, restoring/cloning, zero-fill, capacity tests, Ventoy installation and partition edits can ERASE a drive. Use only a backed-up spare labelled TEST ONLY. Do not interrupt a drive holding personal files. A missing PC or console means Not sure/Blocked, never Worked.

Simple words used in the tests

SHA-256 / fingerprint: 64 letters/numbers identifying a file’s exact bytes. The pack’s HASHES.txt lists the correct values. Compare using the app’s SHA-256 checksum tool; the complete value must match.

Image: a file containing disk or archive data. Our samples are generated data, not bootable systems.

Partition: a section of a drive. Usually select 1 for a whole drive image or normal single-partition USB. Select 0 only when the guide explicitly says the sample has no partition table.

MBR / GPT: two ways a drive describes its partitions. Changing them can affect booting; use a spare.

Independent check: open the output in Android Files, another program or a real computer. The app’s own “success” message is only one part of checking it.

Not sure: you tried but cannot decide, or checked only part of the result. Blocked: you cannot run a required test because equipment/files/access are missing. Explain in notes. Not applicable: outside the features you will publish, with a reason; it is not a shortcut around a supported tool.
